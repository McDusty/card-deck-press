Quick start

  1. Open an empty Penpot page. In Create deck, choose a name, size, and orientation.
  2. Click Create deck. The plugin creates Front, Back, and Artwork frames, then closes.
  3. Design Front. Name variable text or image layers with #, such as #name.
  4. Reopen Card Forge Upgraded. In Edit deck, use Add Card or Import CSV.
  5. Open Export, choose a layout, then click Generate Cards. Sheet layouts offer Download PDF.

Create a deck and choose a size

The Measurements menu shows pixels, inches, or millimeters. Switching units keeps the same physical size.

Pixels use 300 ppi (pixels per inch). Sizes describe the finished card, without extra bleed.

Card size presets
PresetInchesMillimetersPixels at 300 ppi

Choose Custom size to enter your own width and height. Each side must be between 1 and 12,000 px. Portrait places the longer side vertically; Landscape places it horizontally.

For exact 70 × 120 mm Tarot, use Custom size. The Tarot preset is 2.75 × 4.75 inches, or 69.85 × 120.65 mm.

Changing a preset affects new decks. Existing templates keep their dimensions. Correct Poker Size fixes older poker templates and their original inset border, while preserving custom artwork. Generate cards again in Export afterward.

These presets follow one printer's rectangular formats. Circle and hexagon formats are not included.

Design your template

  • Front: the shared design for your card faces. Keep the frame name.
  • Back: one shared back design. It has no per-card variable fields.
  • Artwork: the central place for images used by your cards.

Layers without a # name stay the same on every card. Give each variable layer a distinct name, such as #name, #rules, or #art.

Use a text layer for text fields. For image fields, use a rectangle with one image fill. Design its size and crop in the template.

See Set up a template image for step-by-step image setup and a CSV example.

Fronts-only output needs Front. Backs-only output needs Back. Layouts that include both sides need both frames.

Allow enough space for long names and rules. Automatic text-overflow checking and text shrinking are not available yet.

Edit cards

Import CSV stays on the left and Add Card on the right of the top toolbar in Edit Deck.

An empty deck also shows these two buttons inside the card table. Use either location to start.

  • Add Card: add a row and enter its text or image values.
  • Quantity: set the number of printed copies for that row. New cards start at 1. Use whole numbers from 0 to 100; 0 excludes the card from output.
  • Duplicate / Delete: use the controls beside a card row.
  • Import CSV: preview spreadsheet data before replacing the card list.

Example: add one Healing card and set Quantity to 10. Print sheets include ten copies without needing ten rows. Editing the row updates every copy the next time you generate cards.

Quantities repeat cards in six-up, nine-up, back sheets, and fold-over layouts. Single-card, Standard, and Tabletop layouts include each nonzero design once. Older cards without a quantity count as 1.

Changing Penpot pages reloads the editor for the new page. Image uploads stay attached to their original card; uploads for a removed card or a previous page are discarded.

Text fields support multiple lines. After a CSV import, you can also edit Card ID. Keep IDs unique when preparing another import. The CSV quantity column uses the same Quantity field.

Card edits are saved on the Penpot page. When you are ready, open the Export tab at the top and click Generate Cards. Repeat this after editing cards to update the output.

Import CSV or Google Sheets data

For Google Sheets, download the sheet as CSV, then upload that file. A direct Sheets connection is not available yet.

Use quantity as the CSV column header to map it automatically to each card's Quantity. For example, 001,10,Healing under card_id,quantity,name prints ten Healing cards on sheets. If the quantity column is omitted, every row defaults to 1.

  1. In Edit Deck, choose Import CSV from the toolbar or the empty card table. You can also use Download sample in the import view.
  2. Map columns to Card ID, Quantity, a template field, or Ignore. Matching names map automatically: name → #name.
  3. Review the first five rows, printed-copy count, artwork matches, and added / changed / removed counts.
  4. Fix any reported errors. Click Apply import to replace the whole card list, or Cancel to keep it.
  5. Open Export and click Generate Cards to update the output.
CSV columns
ColumnWhat to enter
card_idA unique, nonblank ID for every row. Keep it stable across updates. 001 stays text.
quantityOptional. Defaults to 1 if the column is absent. Whole numbers 0–100; 0 excludes a card from output. A blank cell in a mapped quantity column is an error.
Text fieldsText, including Unicode, commas, quotes, and line breaks. Quote CSV cells that contain commas or line breaks.
Image fieldsAn exact Artwork image name or path. A blank mapped cell clears the image.

Example for a template with #name, #rules, and #art:

card_id,quantity,name,rules,art
001,3,"Queen, red","First line
Second line",dragon.png
002,1,Joker,"Say ""hello""",
003,0,Unused,Not printed,

Ignored columns are discarded. Unmapped template fields keep their template design. If a mapped layer is renamed, removed, or replaced, review the mapping again.

Import limits: UTF-8 CSV, 2 MiB, 100 columns, 500 records, and 1,000 printed copies.

Set up a template image

Create an image placeholder in Front

  1. Inside Front, draw a rectangle where each card's image should appear.
  2. Give the rectangle one image fill using a sample image.
  3. Name the rectangle after the spreadsheet column containing your image filenames, with # at the start. For example, an art column uses a rectangle named #art; an illustration column uses #illustration. Each variable layer needs a unique name.
  4. Set the rectangle's size and image crop in Penpot.
  5. Reopen Card Forge Upgraded. Edit Deck now shows a column with your chosen name, such as art or illustration.

Add images manually

In Edit Deck, each image cell lets you type an exact Artwork image name or select an image from Choose from Artwork. Press Enter or leave the name field to match it. Use a full path to distinguish duplicate names, such as Artwork/creatures/dragon.png.

Click Upload to add a new image. It is saved in Artwork with its filename and assigned to this card, ready to reuse in other rows or CSV imports. Clear removes the image from this card without deleting it from Artwork.

After adding or renaming images directly in Penpot, click Refresh Artwork to update the choices. Missing or ambiguous names show an error; resolve them before generating fronts. Open Export and click Generate Cards to use your changes.

Match images from CSV

Place your source images in the Artwork frame as rectangles with image fills. Name each image rectangle with its exact filename, such as healing.png.

Use an art column in your CSV. It maps automatically to the template's #art field. For example:

card_id,name,art,quantity
001,Healing,healing.png,10

The Artwork image rectangle must be named healing.png. After applying the import, generate cards in Export. Print sheets include ten copies of this Healing card using that image.

In the import view, choose Add artwork images to upload a batch into Artwork. Each image gets its filename as its layer name.

You can also place image rectangles in Artwork yourself. Older _Images storage still works; it becomes visible Artwork storage when reused for an upload.

  • Exact name: dragon.png. Names are case-sensitive and include the extension.
  • Duplicate names: use a path, such as Artwork/creatures/dragon.png. Make the path unique.
  • Missing or ambiguous image: fix the name or path, then choose Refresh matches. Apply stays blocked until the errors are resolved.
  • Replace an image: replace the fill on the same Artwork rectangle, then generate cards again in Export. Its current image is used.

Batch limit: 100 images totaling 32 MiB. If an upload stops partway through, successfully uploaded images remain in Artwork.

Matching supports raster image rectangles on the current page. Shared Penpot libraries and complex vector components are not supported yet.

Update, export, and restore

Update your spreadsheet, keep the same IDs, and upload a new CSV. Apply replaces the whole list: cards absent from the new file are removed from the list.

Existing generated boards stay in place after import. The out-of-date message means you need to generate cards again in Export.

  • Export CSV: save the current card data for backup and reimporting. Cards without IDs receive generated IDs in the export.
  • Export for spreadsheets: save a viewing copy with formula-like values treated as text. This adds leading tabs to those values. Use the original Export CSV for reimporting; spreadsheet applications may handle text protection differently.
  • Restore previous import: restore one saved snapshot of the card data, mappings, and output settings.

Restore does not undo template or artwork edits and does not regenerate output. Review the restored data, then generate cards again in Export. A later import replaces the stored snapshot.

Choose an output layout

Open Export → Output Layout to choose what to generate.

Choose your layout, paper size, and cut lines, then click Generate Cards. Sheet layouts offer Download PDF once generation succeeds. For single cards, export the generated boards using Penpot.

Switching tabs keeps your output settings and a ready PDF. Editing cards, importing data, or changing output settings requires generating the output again. Use Back to Edit Deck or the top tab to return to your cards.

Backs-only layouts use the shared Back template and the included card count. They do not require Front fields or front artwork.

Quantity 0 excludes a card and its artwork requirements from every layout. Single-front, Standard, and Tabletop layouts include each nonzero design once. Print sheets repeat copies consecutively, in card-list order.

Fronts Output and Backs Output are independent: generating one keeps the other. A successful run replaces its own previous output. Standard, fold-over, and Tabletop modes share their own generated Output frame. Only output owned by this deck is replaced, after the new output completes. Older unclaimed frames named Output are kept; remove them yourself if they are no longer needed. A failed run keeps the last completed output.

Print, cut lines, and bleed

  • Paper: six-up and nine-up sheets default to US Letter portrait. A4 is also available.
  • Spacing: sheets use 5 mm margins and no gaps between cards.
  • Cut lines: default to Yes for sheets. Each shared card edge gets one straight line. Switch them off if you prefer.
  • Card size: cards keep the template dimensions. If the selected grid does not fit, choose another size or layout.

After generating a sheet in Export, click Download PDF. It contains the sheets in order, on physically sized Letter or A4 pages.

Print the PDF at Actual Size / 100%. Turn off Fit to Page. Measure a test card before printing the whole deck.

Editing cards while a PDF is being prepared cancels that download. Generate cards again to download the updated deck. Sheets are processed one at a time to reduce memory use. Very large files are stopped with a size error; reduce quantities or export a smaller selection of cards.

PDF sheets contain 300-ppi images. For single-card images, use Penpot's export controls. Automatic PNG ZIP downloads are not available yet.

Bleed is artwork extending beyond the final cut edge. Card Forge Upgraded's preset frames are the finished size and do not add a printer-specific bleed area. Use your printer's separate requirements when preparing commercial files.

Keep important text and symbols away from the card edge so cutting differences do not remove them.

Fix common problems

Create deck says the page is not empty
Create the new deck on an empty page.
A template field is missing
Check its # name and layer type. Image fields need a rectangle with one image fill.
CSV Apply is disabled
Read the errors. Check IDs, quantities, column mapping, and exact artwork names. Then refresh the preview.
The deck changed after preview
Choose Refresh matches to get a fresh preview before applying.
Cards do not fit the sheet
Choose a compatible card size or layout, or use single cards. Large and Tarot cards may not fit a three-row sheet.
The PDF button is missing
Select a six-up or nine-up sheet layout in Export and click Generate Cards first.
Printed cards are the wrong size
Check the template dimensions and print scaling. A PNG's pixel count alone does not set its physical print size; use the sheet PDF for physical page sizing.
Changes do not show in output
Generate cards again in Export after editing card data, the template, or artwork. Reopen the plugin after a local plugin rebuild.
